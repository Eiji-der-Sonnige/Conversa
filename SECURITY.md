# Sicherheitsrichtlinie

Conversa ist ein nicht-kommerzielles Hobbyprojekt ohne Gewährleistung. Hinweise auf Sicherheitslücken
sind trotzdem sehr willkommen.

## Sicherheitslücke melden
- Bitte **keine öffentlichen Issues** für Sicherheitslücken anlegen.
- Stattdessen über GitHub melden: **Security → Report a vulnerability** (private Sicherheitsmeldung).
- Bitte möglichst beschreiben: betroffene Version, Schritte zur Reproduktion, mögliche Auswirkungen.

Es gibt keine garantierten Reaktionszeiten. Bestätigte Lücken werden nach Möglichkeit behoben und in den
Release-Notizen erwähnt.

## Unterstützte Versionen
Nur die jeweils neueste Version unter **Releases** erhält Sicherheitskorrekturen.
